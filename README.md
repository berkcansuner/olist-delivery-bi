# Olist Delivery BI

**Business question:** How much do late deliveries hurt customer review scores, and which sellers and regions drive the problem?

End-to-end BI project on the public Olist e-commerce dataset: SQL profiling and modeling in DuckDB, a star schema, data quality checks that run with the build, and a Power BI report.
